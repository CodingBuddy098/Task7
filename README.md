# 📊 Task 7 - Basic Sales Summary using SQLite and Python

This project was completed as part of a Data Analyst Internship task. It demonstrates how to use SQL within Python to extract, summarize, and visualize simple sales data from a SQLite database.

## Objective

- Connect to a SQLite database (`sales_data.db`)
- Query basic sales information (total quantity sold and total revenue per product)
- Display results using `print()` and `matplotlib` bar charts

## Tools & Libraries Used

- Python 3
- SQLite (`sqlite3`)
- pandas
- matplotlib
